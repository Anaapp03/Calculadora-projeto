# Calculadora em Python 

Projeto desenvolvido para praticar lógica de programação em Python, contendo validações de entrada e tratamento de erros.

## Funcionalidades
- Versão de terminal com validações completas (tratamento de divisão por zero e letras inválidas).
- Versão com interface gráfica simples utilizando **Tkinter**.

## Tecnologias Utilizadas
- Python 3
- Tkinter (para a interface gráfica)
